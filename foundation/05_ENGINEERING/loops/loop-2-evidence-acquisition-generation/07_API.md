```
Institutional Event
      ↓
SourceRecord
      ↓
Generation Rule
      ↓
Evidence (evidence_nodes)
      ↓
ClaimEvidenceLink
      ↓
Claim
      ↓
Review
      ↓
Passport
```

## 2. Current FK Path (Implicit Graph)

The lineage graph is implicit in existing FK relationships:

```
institutional_events.id
      ↓ (correlation_id links events to source acquisitions)
source_records.source_record_id (or evidence_source_id for non-event sources)
      ↓ (evidence_nodes.source_record_id, added in 077)
evidence_nodes.id
      ↓ (claim_evidence_links.evidence_id, PK 078)
claim_evidence_links.claim_id
      ↓
claims.id
      ↓ (review_tasks.claim_id, 060)
review_tasks.id
      ↓ (passport_entries claim_id — need to verify FK)
passport_entries.id
```

**No separate lineage table needed.** The graph is traversable via joins.

## 4. Required Lineage Queries

| # | Query | Input | Output | Implementation |
|---|-------|-------|--------|----------------|
| 1 | Trace full lineage | evidence_id | Full chain: event→source→rule→evidence→claim→review→passport | Multi-join query |
| 2 | Trace source to evidence | source_record_id | List of evidence_nodes generated from this source | WHERE source_record_id = ? |
| 3 | Trace rule to evidence | rule_id | List of evidence_nodes generated by this rule | WHERE generation_rule_id = ? |
| 4 | Trace claim to evidence | claim_id | List of evidence + links | JOIN claim_evidence_links |
| 5 | Trace evidence to source | evidence_id | SourceRecord + EvidenceSource | FK chain |
| 6 | Trace event to evidence | event_id | All evidence derived from this event (via source_records) | correlation_id chain |

## 5. Design: LineageService Implementation

```typescript
class LineageService {
  // Full lineage: evidence → source → rule → claim → review → passport
  async traceLineage(evidenceId: string): Promise<FullLineage>

  // Upstream: what produced this evidence?
  async traceProvenance(evidenceId: string): Promise<ProvenanceChain>

  // Downstream: what claims/reviews/passports depend on this evidence?
  async traceDependents(evidenceId: string): Promise<DependentChain>

  // By source: what evidence came from this source?
  async traceFromSource(sourceRecordId: string): Promise<Evidence[]>

  // By rule: what evidence was generated by this rule?
  async traceFromRule(ruleId: string): Promise<Evidence[]>
}
```
