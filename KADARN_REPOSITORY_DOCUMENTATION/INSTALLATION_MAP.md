# Repository Installation Map

Place the contents of this package at the root of the canonical KADARN repository.

## Root files

- `START_HERE.md`
- `PROJECT_STATE.md`
- `DOCUMENT_MAP.md`
- `AGENTS.md`

## Documentation tree

Copy the complete `docs/` directory into the repository.

## Existing-file safety

If the repository already has any root file with the same name:

1. Do not overwrite it blindly.
2. Compare its purpose and content.
3. Merge compatible instructions.
4. Preserve any repository-specific commands, constraints, and paths.
5. Record the merge in the next commit or Work Order evidence.

After installation, the only required follow-up is a read-only implementation reconciliation that replaces the “reported” status in `PROJECT_STATE.md` with evidence from the selected commit.
